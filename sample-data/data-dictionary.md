# Data Dictionary

> **All sample data is synthetic.** Every person, alias, number, date, queue name and schedule was generated by [`scripts/generate-synthetic-data.ts`](../scripts/generate-synthetic-data.ts) (seed 42). Nothing comes from a real roster or a real contact-center export. The files only mirror the column layout, so the app can be demoed and tested.

Regenerate at any time:

```bash
npm run generate-data              # same files every time (seed 42)
npm run generate-data -- --seed 7  # a different synthetic day
```

## How the generator builds a metrics row

1. Intervals are created where the agent's shift overlaps 09:00–17:00, minus PTO.
2. Break (≈15 min) and lunch (≈30 min) seconds are placed at the roster times.
3. Personal, huddle, training, unproductive and approved time are added at random rates.
4. Available = online − non-productive. Contact = available × the agent's occupancy level ± noise (morning intervals slightly busier, late afternoon quieter).
5. Contacts = contact ÷ an AHT drawn around the roster baseline. One agent (`umbquim`) runs 50% slower than baseline and one (`caswhit`) has a low occupancy level, so the flags have something to show.
